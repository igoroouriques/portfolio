## 📖 Sobre o projeto

Meu portfólio pessoal, feito para apresentar quem eu sou como estudante de Engenharia de Software de um jeito divertido. Em vez de uma página séria e igual a todas as outras, montei uma "base de dados" dos Autobots: com dossiê do operador, árvore de habilidades, quiz, terminal interativo e um botão que transforma o site inteiro.

Tudo foi feito com **HTML, CSS e JavaScript puros**, sem frameworks e sem bibliotecas.

## ✨ Destaques

- 🔄 **Botão "Transformar!"** que alterna o site entre o tema azul dos **Autobots** e o tema roxo dos **Decepticons**. Mudam cores, textos, personagem em destaque, estatísticas e até a missão, com um efeito de glitch na troca.
- 🗂️ **Dossiê do operador** com ficha de identidade e barras de status animadas.
- 🧪 **Diagnóstico de sistemas:** um botão que escaneia o "operador" e sorteia uma mensagem diferente.
- 🌳 **Árvore de habilidades** com cartões e barras de progresso.
- 🎯 **Simulador de destino:** um quiz de uma pergunta que revela qual Transformer mora em você.
- 💻 **Terminal cybertroniano:** digite comandos e receba respostas (veja a lista abaixo).
- 🧭 **Menu fixo** com versão para celular, faixa de frases em movimento e efeito de brilho que segue o cursor.
- 📱 **Responsivo:** layout adaptado para desktop, tablet e celular.
- ♿ **Acessibilidade:** respeita a opção "reduzir movimento" do sistema, usa `aria-live` nas mensagens dinâmicas e tem textos alternativos nas imagens.

## 💻 Comandos do terminal

## 🚀 Como rodar

Você só precisa de um navegador moderno (Chrome, Edge, Firefox ou Safari). As fontes vêm do Google Fonts, então a **internet** deixa o visual como foi pensado. Sem ela, o site usa fontes alternativas e continua funcionando.

### Opção 1: baixar e abrir (mais simples)

1. Na página do repositório, clique em **Code → Download ZIP**.
2. Extraia o arquivo `.zip`.
3. Dê dois cliques em **`index.html`** para abrir no navegador.

### Opção 2: clonar com Git

```bash
git clone https://github.com/igoroouriques/portfolio.git
cd portfolio
```

Depois abra o `index.html` no navegador.

### Opção 3: VS Code com Live Server (recomendado para editar)

1. Abra a pasta do projeto no VS Code.
2. Instale a extensão **Live Server**.
3. Clique com o botão direito em `index.html` e escolha **Open with Live Server** (ou clique em **Go Live**, no canto inferior direito).

### Opção 4: servidor local com Python

```bash
python -m http.server 8000
```

Acesse `http://localhost:8000`.

## 🌐 Publicação

O site pode ser publicado de graça com o **GitHub Pages**:

1. Vá em **Settings → Pages** no repositório.
2. Em **Source**, escolha **Deploy from a branch**.
3. Selecione a branch **main** e a pasta **/ (root)**, e clique em **Save**.
4. Em 1 a 2 minutos, o link aparece no topo da página de Pages.

> Para o GitHub Pages abrir o site, o `index.html` precisa estar na raiz do repositório.

## 🎯 O que foi praticado

- Organização de uma página única com várias seções
- Temas visuais trocados em tempo real com JavaScript e classes CSS
- Animações com `@keyframes`, transições e efeitos de glitch
- Layout responsivo com Grid, Flexbox e media queries
- Manipulação do DOM e eventos em JavaScript puro
- Acessibilidade básica e cuidado com `prefers-reduced-motion`
